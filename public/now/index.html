I'm an Engineering Manager who still ships. In my current role I own one B2B SaaS product end to end: an Electron desktop client, a React web app, and Node.js services on AWS. This page is the recent record, dated and specific, with the product and customer names left out.

Timeline

The last three weeks, in order

Newest first. Each entry is something that reached staging or production.

  1. 24 Nov 2026ProductionDatabase

    Fixed the root cause of an outage with zero downtime

    Added the missing composite index to the busiest table online, with no lock and no maintenance window, then merged guard rails so the same query shape cannot reach production again.

    Four production releases went out the same day, each with a rollback path.

  2. 23 Nov 2026Incident

    Diagnosed a production slowdown to one query pattern

    Reads that normally take milliseconds were running for more than 800 seconds and holding the database at its I/O ceiling. I traced it to history scans from one dashboard, mitigated it the same day, and wrote up the cause and the fix.

  3. 23 Nov 2026ProductionReal-time

    Stood up a production video-calling service

    Deployed a selective-forwarding (SFU) media service on AWS ECS with fixed media ports, separate from the main API, and verified calls and screen sharing end to end.

  4. 22–23 Nov 2026DesktopRollout

    Put the rebuilt desktop app in front of a pilot group

    Shipped signed pre-release builds for macOS (Apple Silicon and Intel) and Windows (installer and MSI), released them to a pilot team on production, and supported those users directly while watching the telemetry.

  5. 20–22 Nov 2026Security

    Ran a security hardening sprint from scan to production

    Security headers and a report-only Content Security Policy on the production web app, an HTTPS-only API, DNSSEC signing with keys held in a managed KMS, DMARC monitoring on the mail domain, and a runtime upgrade to Node 22 on staging.

  6. 21 Nov 2026ProductionRelease engineering

    Released the new web and API generation overnight

    A written runbook, a database snapshot, and a named rollback target before the first command. The release ran in the customer's quiet hours and nobody noticed, which is the point.

  7. 10 Nov 2026DesktopPlatform

    Moved the desktop client from Electron 25 to Electron 45

    Twenty major versions in one planned upgrade: a new security model (narrowed entitlements, encrypted local captures, a strict CSP), silent auto-updates, and a tracking pipeline rebuilt so that it does not lose data when the app restarts.

    I also designed a bridge release so that the installed base moves to the new generation without anyone reinstalling.
